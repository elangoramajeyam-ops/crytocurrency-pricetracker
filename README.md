# Cryptocurrency Price Tracker

A simple and user-friendly **Cryptocurrency Price Tracker** that displays real-time cryptocurrency prices and market information. The website helps users quickly check the current price and basic details of popular cryptocurrencies.

## 🚀 Features

* 📈 View cryptocurrency prices
* 💰 Display current market values
* 🔄 Fetch updated cryptocurrency data
* 🔍 Search for cryptocurrencies
* 📊 Display cryptocurrency information in an easy-to-understand format
* 🖥️ Simple and responsive user interface
* ⚡ Fast and lightweight application

## 🛠️ Technologies Used

* **Python**
* **HTML**
* **CSS**
* **JavaScript**
* **Cryptocurrency API**
* **Flask** (if used in the project)

## ⚙️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/cryptocurrency-price-tracker.git
```

### 2. Open the Project Folder

```bash
cd cryptocurrency-price-tracker
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python crypto_tracker.py
```

### 5. Open in Browser

Open:

```text
http://127.0.0.1:5000
```

## 📊 How It Works

1. The user opens the Cryptocurrency Tracker website.
2. The application connects to a cryptocurrency API.
3. The API provides the latest cryptocurrency information.
4. The application processes the received data.
5. The cryptocurrency price and details are displayed on the website.
6. Users can search and view different cryptocurrencies.

## 🎯 Purpose of the Project

The main purpose of this project is to create a simple platform for tracking cryptocurrency prices and understanding how **APIs, Python, web development, and real-time data** can be integrated into a single application.
